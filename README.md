# Quantum & MLOps Governance Terminal

Dashboard ejecutivo en Streamlit para demostrar gobierno cuantitativo, control
de calidad, riesgo dinámico y trazabilidad MLOps con datos sintéticos.

## Ejecutar

```bash
pip install -r requirements.txt
streamlit run app.py
```

La demo no ejecuta órdenes, no se conecta a brokers y no constituye asesoría
financiera. El botón **Inyectar Cisne Negro** altera únicamente la simulación en
memoria y permite mostrar el flujo de detección de drift.
